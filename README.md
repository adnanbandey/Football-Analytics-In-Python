# ⚽ Football Analytics Projects

This repository is a collection of all my football-related analytics work—past, present, and future. It includes data explorations, match insights, performance breakdowns, and visual storytelling across different leagues and datasets.

Each notebook is a standalone project focused on a specific question or dataset, aimed at sharpening my skills in data analysis, visualization, and sports intelligence.

## 💡 Topics Covered

- Team and player performance analysis  
- Match outcome trends  
- Goal statistics and defensive profiles  
- Home vs. away dynamics  
- Custom visualizations and metrics  

## 🛠️ Tools Used

Python, Pandas, Seaborn, Matplotlib, Jupyter, Selenium (for scraping)
